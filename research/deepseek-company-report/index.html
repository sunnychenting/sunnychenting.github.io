一、公司阶段判断

DeepSeek 正在经历一个关键的组织跃迁：

2024年          2025年           2026年           2027年+
  │               │                │                │
  ▼               ▼                ▼                ▼
探索期(0-1) → 高速增长期(1-10) → 成熟/转型期 → 规模化公司
  │               │                │                │
  百人研究      技术突破+开源      七层扩张+        商业化+
  组织          影响力爆发        组织建设         流程固化
  │               │                │                │

关键判断：

  • 早期以约百人级的高密度研究团队形成技术突破
  • 进入2026年后，公司正在从”小规模前沿研究组织”向更大规模的研究、工程、基础设施、产品和商业化组织扩张
  • 2026年6月官方招聘已进入明显扩张阶段，岗位覆盖全栈开发/算法、AI核心系统研发、运维、产品、模型数据策略、深度学习研究、HR、法务、财务、采购、行政、AGI核心业务管培生
  • 工作地点已扩展到北京、杭州、乌兰察布

二、七层组织结构

基于截至2026年8月的公开招聘信息，DeepSeek 的组织能力正在变厚，已形成以下七层结构：

① Frontier Research（前沿研究）

负责方向：新模型范式、预训练、后训练、RL、多模态、持续学习、自进化

官方招聘岗位：

  • Frontier（持续学习/自进化/新范式）研究员
  • 预训练研究员
  • 后训练研究员
  • 多模态理解研究员

组织信号：已不是简单的”一个大模型研发组”，而是在形成研究方向矩阵。

② AI Core Infrastructure（AI 核心基础设施）

负责方向：训练框架、推理框架、高性能算子、通信、编译器、分布式存储、超算集群、AI平台运维、IDC

官方招聘岗位：

  • 核心系统研发工程师
  • 高性能算子工程师
  • 通信/编译器工程师
  • 分布式存储工程师
  • 超算集群研发工程师
  • AI平台运维

组织信号：DeepSeek 的竞争力并不是单纯来自”几个算法天才”，而是算法、模型、系统、算力基础设施之间的耦合。

③ Agent / Application（智能体与应用）

负责方向：Agent Harness、Agent Infra、AI搜索、Agent后端、AI产品、通用Agent数据产品、Code Agent

官方招聘岗位：

  • Agent后端工程师
  • AI产品经理
  • AI搜索工程师
  • Code Agent工程师

组织信号：DeepSeek 正在从**“模型研究公司”向”AI基础模型 + 基础设施 + Agent + 产品生态”扩展。**

④ Data / Evaluation（数据与评估）

负责方向：数据策略、数据工程、Evaluation、Code Agent数据、专业领域数据、情感智能数据

官方招聘岗位：

  • 模型数据策略工程师
  • 数据工程工程师
  • Evaluation工程师

组织信号：“模型数据策略”已成为独立类别。数据不再是简单的模型研发辅助岗位，而正在成为独立能力域。

⑤ Product / Commercialization（产品与商业化）

负责方向：AI产品经理、AI产品运营、AI搜索、Agent、API、App、企业相关能力

官方招聘岗位：

  • AI产品经理
  • AI产品运营
  • AGI核心业务管培生

组织信号：DeepSeek 从”技术组织”走向”大公司”的关键观察点。技术成果能否变成产品能力，将决定其长期价值。

⑥ Corporate Functions（职能支持）

负责方向：HR、法务、财务、采购、行政

组织信号：组织正在经历从”研究型创业团队”进入”规模化公司建设阶段”。未来的岗位类型会明显变多。

⑦ Compute / Data Center（算力与数据中心）

负责方向：超算集群、IDC数据中心、高性能分布式存储、通信/编译器/算子

官方招聘岗位：

  • 超算集群研发工程师
  • IDC数据中心团队
  • 高性能分布式存储工程师

工作地点：北京、杭州、乌兰察布

组织信号：DeepSeek 与普通 AI 创业公司的重大不同是对计算资源的依赖极重。已形成”模型研究 → 算力基础设施 → 训练 → 推理 → 产品”的完整技术链。

五、组织文化

五个核心特质（基于创始人公开访谈）

1. 不预先严格分工

梁文锋公开表述：“我们也不预先设定角色，分工是自然形成的。”

  • 不是：Leader → 分配任务 → 员工执行
  • 而是：人 → 兴趣/能力 → 自发探索 → 拉人合作 → 形成团队 → 资源投入

2. 资源跟着”想法”走，而不是跟着职位走

如果有人有想法，可以调用训练集群，不需要传统意义上的层层审批；团队成员之间也可以自由协作。

  • 组织权力的一部分从”职位”转移到了”想法 + 能力”
  • 年轻研究员可以产生非常大的影响

3. 不鼓励传统意义上的”赛马”

  • 传统互联网：A团队做方案A，B团队做方案B，最后PK
  • DeepSeek：一个人发现问题 → 自己探索 → 拉感兴趣的人 → 验证 → 证明有潜力 → 组织投入资源

4. 淡化职级、扁平组织

  • 不是：职级 → HC → 晋升 → 管理者评价
  • 而是：Idea → Technical Breakthrough → Impact → Recognition

5. 自下而上的探索

梁文锋认为创新需要尽可能少的干预和管理，强调自下而上的探索机制。

六、晋升逻辑

DeepSeek 的晋升逻辑可能与传统大厂完全不同：

维度传统大厂（阿里/字节）DeepSeek
晋升依据绩效 + 职级 + 答辩 + 组织关系Idea → Breakthrough → Impact → Recognition
权力来源职位 + HC + 预算审批权想法 + 技术影响力 + 资源获取能力
成功标准KPI/OKR 完成度技术突破/论文/开源影响力
失败容忍低（361/末位淘汰）较高（研究失败可接受，但长期无产出不可接受）

关键判断：

  • 在传统大厂：年龄 + 职级 + 组织关系权重较高
  • 在 DeepSeek：问题难度 + 技术贡献 + 原创性 + 影响力权重可能更高
  • 这是典型的”能力密度组织”
  • “没有想法”比”想法失败”更危险

七、组织适配度

高度适合

  • 极强技术能力
  • 极强自驱
  • 喜欢研究未知问题
  • 不需要别人每天告诉你做什么
  • 能接受长期试错
  • 有强烈创造欲
  • 能快速学习
  • 对技术问题本身有兴趣

不适合

  • “我希望有非常清晰的晋升标准”

十一、关键结论

  1. DeepSeek 不是”年轻人的天堂”：它的组织模式有非常强的适配性要求，不适合需要明确指令和 KPI 的人
  2. 岗位差异远大于公司差异：进入 AI Core Infra 和进入 Corporate Functions，完全是两种职业轨迹
  3. 2026 年是转型窗口期：组织正在从研究型向规模化过渡，文化稀释和政治化风险正在上升
  4. 薪酬高但不是所有人都高：核心算法岗位顶薪极高，但职能/支持岗位与行业持平
  5. 退出流动性取决于岗位：Infra 岗位的资本通用性最高，Research 岗位的流动性最窄但溢价最高

本报告基于截至 2026年8月的公开信息整理，后续将持续跟踪更新。

第十三章：执行摘要

一句话：DeepSeek 是”能力密度组织”，正处于研究型 → 规模化的转型窗口期——适合自驱、强技术、能接受模糊与试错的人；不适合需要明确指令/KPI/清晰晋升路径的人。

5 条核心结论：

  1. 岗位差异 > 公司差异：进 AI Core Infra（第二层）和进 Corporate Functions（第六层）是两种完全不同的职业轨迹——先选层，再选公司
  2. 薪酬高但不是全员高：核心算法岗顶薪极高，职能岗与行业持平——别被顶薪数据误导
  3. 晋升逻辑是”Idea → Breakthrough → Impact → Recognition”：传统大厂”绩效+答辩+组织关系”打法在此可能失效；“没有想法比想法失败更危险”
  4. 2026 是窗口期也是风险期：文化稀释/政治化/岗位定义化/预算制正在发生，入场要带着”反向尽调”进
  5. 退出流动性取决于岗位：Infra 资本通用性最高，Research 溢价最高但流动性最窄

分职级决策建议：

  • P6：优先 Agent/Infra 应用层（进得去、可迁移），避开纯 Research（难出头）
  • P7：优先 Infra 架构 / 独立研究方向岗（高曝光、好积累）
  • P8：优先 Infra 战略 / 研究方向定义岗，且必须带 90 天着陆验证清单（组织转型期文化变味风险最高）
