数据分析

「取数—报表—描述现象」的岗位正在承压。真正要问的是：你在生产数据，还是在用数据解决业务问题？

能去哪（7 条出口）
产品数据分析 → 产品经理 横向 增长 / 策略 → 策略负责人 横向 经营分析 → 商业分析 / 战略 横向 风险分析 → 风险策略 横向 BI / 数据产品 → 数据产品管理 横向 数据科学 / 算法 相邻岗位 分析师 → 高级 → 专家 → 负责人 纵向
真正的分叉

数据生产型 → 问题解决型 / 业务分析 → 专业分析 / 支持业务 → 参与决策

最常见的陷阱

停在取数、报表、描述现象——这类工作正被工具和 AI 压缩得最快。

判断依据来自

公开招聘 JD 与职责链路 · 企业生命周期与岗位分型 · 一线从业者访谈

还需要你去验证

你现在的岗位是「生产数据」还是「用数据解决业务问题」 · 所在业务线是否允许你参与决策

综合统一版

HR

生存逻辑正从「处理人与流程」，转向「在业务变化、组织成本、人才供给和劳动风险之间承担决策责任」。

能去哪（9 条出口）
TA → HRBP 从找人到用人 HRBP → OD 组织设计 HR → C&B 分配机制 HR → ER 劳动关系 HR → 出海 HR 国际化 HR → HR Tech 数字化 HR → HR 数据合规 法律兜底 HR → 乙方服务（猎头 / RPO / 咨询） 专业变现 HR → 业务管理 暗线
真正的分叉

执行型 → 决策型 / 专业深度 → 业务纵深 / 流程权力 → 结果责任

最常见的陷阱

把「决策型 HR」当成普适答案——有一批人靠深度专业活得很好，平移过去反而更快出局。

判断依据来自

岗位分型与真实需求 · 细分子赛道与出海状态 · JD 采集与数据纪律

还需要你去验证

你是「能上决策桌的人」还是「该把专业做深的人」 · 所在组织有没有实体决策权
