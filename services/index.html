DIRECTION

岗位方向验证

我到底应该往哪个方向找？

699 元

适合什么情况

  • 不满意现在的工作，但不知道应该转什么
  • 在几个方向之间摇摆，不知道哪个真正适合
  • 需要用真实 JD 来验证，而不是凭感觉判断

不适合什么情况

  • 你已经明确「我就是要投 XX 岗位」—— 那直接做目标岗位简历重构就好

需要你提供 / 参与

  • 按约定完成岗位搜索、收集真实 JD
  • 提交真实信息、记录疑问，并按反馈继续验证

具体交付什么

  • 优先方向
  • 备选方向
  • 匹配依据
  • 待验证问题

结束与后续范围： 我提供的是方法、校准和判断，不替你完成整个市场调研。服务结束后提供约定范围内的一次澄清，不做无限跟进。

什么时候该看另一项： 方向已经明确，需要针对某个岗位重写简历 —— 看那一项 →

RESUME

目标岗位简历重构

我的经历怎么证明我适合这个岗位？

799 元

适合什么情况

  • 已经明确要投哪个岗位
  • 经历不差，但简历讲不出匹配度
  • 投了很多份，回应寥寥

不适合什么情况

  • 大范围职业探索
  • 无限更换目标岗位
  • 系统的职业规划
  • 完整的职业叙事
  • 全套面试辅导
  • 求职陪跑

需要你提供 / 参与

  • 真实、完整的项目经历和事实（会通过「角色 → 动作 → 难点 → 结果 → 可迁移能力」逐项挖掘）

具体交付什么

  • 目标岗位拆解：核心职责、能力要求、招聘方关注的证据
  • 经历挖掘与履历重构：建立「经历 → 岗位要求 → 能力证据」的对应关系
  • 一份目标岗位定向简历

结束与后续范围： 目标岗位在岗位族内小幅调整，在原范围内处理；若原有分析和简历逻辑失效，需重新评估服务范围；再次发生重大方向变化，重新报价。

什么时候该看另一项： 经历跨度大、需要整体职业叙事（简历 + 面试表达） —— 看那一项 →

NARRATIVE

职业履历与求职叙事重构

我到底是谁、为什么这样走、怎么讲清楚？

1299 元

适合什么情况

  • 经历跨度大，讲不出主线
  • 面试总在中途讲不下去
  • 准备一次重要的跳槽或转型

不适合什么情况

  • 只是想改一份简历的措辞 —— 那用 799 就够了
  • 需要长期持续陪伴 —— 那属于求职陪跑

需要你提供 / 参与

  • 参与职业经历与求职经历的梳理，提供真实事实

具体交付什么

  • 职业线因果链：经历 → 选择 → 能力积累 → 变化 → 当前目标
  • 目标岗位匹配逻辑：我的能力 → 岗位需要什么 → 为什么匹配
  • 简历重构
  • 核心面试表达：自我介绍、离职原因、转岗原因、核心优势、重点项目

结束与后续范围： 交付标准是：你拥有一套完整、连贯、可信、能支撑目标求职方向的职业叙事。重点不是背答案，而是理解自己的叙事逻辑。
